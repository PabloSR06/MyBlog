
# Automate your productivity: integrate Google Calendar with Claude using MCP


Are you someone who prefers to plan the entire week in advance, or do you like to take each day as it comes? 

The use of external tools expands the potential of LLMs, allowing them to perform tasks that were previously beyond their reach. These tools communicate using the MCP (Model Context Protocol), so your chat can make use of different functionalities to expand the information they have, broadening the context and making fewer mistakes, but also allowing the model to make changes to the data.

One of these connectors, which we will look at here, is an MCP server for managing your calendar, allowing you to organize yourself with the help of an agent that can suggest what time to schedule appointments. 



## What is an MCP server?
MCP is a protocol designed to allow language models to access external services in a secure and standardized way.

Think of MCP as a “bridge” that allows different models such as ChatGPT, Claude, and others to not only answer questions about your data, but also perform real actions on your applications.

For this example, we have a Google calendar and an MCP server that will allow us to:

- Create events and meetings
- List your schedule
- Search for specific events
- Update existing events
- Cancel events
- Check the current date and time
- Manage Google tasks

## Improve performance with a specialized agent

Although you can invoke MCP tools from any chat, the experience improves when you design an agent with a clear purpose. Without that context, the model may make mistakes (for example, listing historical events instead of consulting the current agenda).

To create an effective agent, the prompt should include:

**Basic elements:**
- Specific role and purpose
- Expected response format

**For complex cases, add:**
- Examples of successful interactions
- Error handling and edge cases
- Priorities when there are conflicts
- Security and privacy restrictions
- When to use the tools available



If your chat has memory to remember things you've said in the past, great. Alternatively, this can also be added to the prompt. For example, if you want it to organize your week and you already have certain routines that you always do, such as going to the gym four days a week, you can describe this in the system prompt and each time you ask for something gym related here is where the information will come from.  

### Prompt template

```
You are an assistant specializing in calendar management. Your goal is to help the user organize their time efficiently using the available MCP tools.

**Important rules:**
1. ALWAYS check the current date before performing operations
2. When listing events, include: title, date, time, duration
3. When creating events, confirm the details before proceeding
4. If there are scheduling conflicts, notify and suggest alternatives
5. Use 24-hour format for times (2:00 PM, not 14:00)

**Response format:**
- Be concise but informative.
- Confirm the actions taken.
- Suggest next steps when relevant.
- When creating an event, inform about previous and subsequent events. 

```

With just this prompt, which is quite basic, we have already greatly improved the experience of talking to our calendar. We can continue to modify and improve it over time.

## Using the server
The code is on GitHub: https://github.com/PabloSR06/mcp-google-calendar


There are two ways to connect to an MCP server: via stdio and via SSE (Server-Sent Events) with streaming. In this tutorial, we will use a stdio connection.

### What is stdin/stdout and how does it work?

Stdio (standard input/output) is a form of inter-process communication in which a program can send or receive data through standard input (stdin) and output (stdout). It is simple, efficient, used for integration between services and scripts, allowing one process to send data to another  in real time.

It is not necessary to clone the entire repository, as many MCP clients can run packages directly with npx. Here you can see an example configuration where you only need to tell what package to use and pass the necessary env keys.


```json
{
  "mcpServers": {
    "mcp-google-calendar": {
      "command": "npx",
      "args": ["-y", "@pablosr/mcp-google-calendar"],
      "env": {
        "GOOGLE_CLIENT_ID": "${GOOGLE_CLIENT_ID}",
        "GOOGLE_CLIENT_SECRET": "${GOOGLE_CLIENT_SECRET}",
        "GOOGLE_REFRESH_TOKEN": "${GOOGLE_REFRESH_TOKEN}"
      }
    }
  }
}
```


This example shows a server designed for single-account use, meaning that everyone would use the same calendar, but it can be easily modified so that each person who uses it can use their own account.


It is important to note that the protection of your data depends on the environment in which you use it. Depending on the model you are using, it may use your conversation to improve its training. In addition, security also varies depending on the application through which you access it, as you may be using a GPT model integrated into another platform.

The models published on Azure offer data protection and comply with the General Data Protection Regulation (GDPR), ensuring an adequate level of security and privacy for your information. On the other hand, the connection with Google is made directly through its own APIs, which also implies certain standards and security conditions in the handling of your data.
